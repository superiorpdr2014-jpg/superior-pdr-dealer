路徑上連不到 `superior-pdr-calculator`（正式版不可外流）。

## 與正式版（superior-pdr-calculator）的差異

| 項目 | 正式版 | 車行版 |
|---|---|---|
| 服務分類 | PDR／保險桿與鈑金烤漆／重機油箱土除／汽機車車牌 | **只有 PDR ＋ 重機油箱/土除** |
| 車身圖 | 含前／後保險桿可點選 | **保險桿已移除** |
| 修復因素 | 全部 | **移除 加固鈑件・經典古董車金屬・稀有車款・側向張力** |
| 修復模式 | 可切換 2opt／3tier／固定 × 範圍／精確 | **鎖定「精緻修復 - 大概修復」× 範圍模式** |
| 修復等級說明 | 無 | 頁面與估價單都附 <https://tar-tw.com/quality/> |
| 操作流程 | 手風琴，一步步展開 | **全部展開，一頁到底** |
| 輸出 | 預覽／訊息內容／簡訊／Email／傳對話／LINE／保險估價單 | **只有「儲存／下載」估價圖** |

## 檔案

- `index.html` — 整包計算器（單檔）
- `config.js` — 價格與修復因素**實際生效在這裡**（改因素改這支）
- `logo.png`、`robots.txt`

## 怎麼更新

車行版是從正式版 `superior-pdr-calc-deploy/index.html` 產生的。
正式版有新功能要同步過來時，重跑產生腳本再核對一次差異表，不要手改整份。
